# SARS-CoV-2 in Pregnancy

This repository contains public data files, analysis code, and supporting information for a project studying SARS-CoV-2 infection during pregnancy.

## Repository Structure

```
.
├── data/        # Public data files (e.g., metadata, processed datasets)
├── code/        # Analysis scripts and pipelines
└── results/     # Figures, tables, and other output files
```

## Overview

This project investigates SARS-CoV-2 infection in pregnant individuals. The repository is maintained by the [DHO Lab](https://github.com/dholab) at the University of Wisconsin–Madison.

## Data

The `data/` directory contains publicly shareable data files associated with this study. Raw sequencing data, where applicable, is deposited in NCBI's Sequence Read Archive (SRA).

## Code

The `code/` directory contains scripts and pipelines used to analyze data for this project.

## Results

The `results/` directory contains summary figures, tables, and other output files generated from the analyses.
